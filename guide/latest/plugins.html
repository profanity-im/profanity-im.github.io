Plugins

Profanity supports plugins written in Lua.

The community-plugins repository collects plugins used by the author and community.

For more details on plugin management, see the /plugins command reference.

Please note: Python and C plugins are no longer supported. If you are looking for information regarding Python and C plugins, please refer to the user guides for version 0.19.0 and older.
